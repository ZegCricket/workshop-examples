# Instrumentation Workshop Examples
This repository contains the Bonsai workflows and the Python Jupyter Notebook showed in the `Integration between Harp and Bonsai` module of the Instrumentation Workshop.

## Installation
To install Bonsai, run the `Setup.cmd` script that is located inside the `.bonsai` folder.

To install the Python environment:
1. Install [uv](https://docs.astral.sh/uv/getting-started/installation/).
2. Run `uv sync` inside the `python` folder.
